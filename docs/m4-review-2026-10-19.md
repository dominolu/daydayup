## P1 修复明细

| # | 问题 | 影响 | 修复 |
|---|---|---|---|
| 1 | `rewriteChunk` 对"usage 与 choices 打包在同一 SSE 事件"的上游提前返回，丢掉最终文本 delta 与 `finish_reason` | 流式尾部截断、终结信号丢失，Agent 可能挂起 | usage 与 choices 在同一事件中一并重建（`TestMiddlewareUsageBundledWithChoices`） |

| 3 | `rawSwitcher.setRaw` 只标记最外层 writer：中间件+协议桥同时开启、流式请求遇上游回 JSON 时，外层透传但内层 SSE 编码器吞掉 JSON | 客户端静默悬挂 | setRaw 沿 writer 链级联传播（`TestMiddlewareBridgeCascadeRaw`） |
